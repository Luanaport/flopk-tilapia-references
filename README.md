# FloPK Tilápia — Referências

Repositório público com as referências bibliográficas e os recursos técnicos relacionados ao desenvolvimento do **FloPK Tilápia**, simulador farmacocinético de florfenicol em tilápias-do-nilo (*Oreochromis niloticus*).

## Acessar a página de referências

Após a ativação do GitHub Pages, a página estará disponível em:

https://Luanaport.github.io/flopk-tilapia-references/

## Conteúdo

A página reúne os artigos científicos de base, a documentação do R e a documentação do Simulx/MonolixSuite utilizados como referências no projeto.

## Software

- R version 4.6.0 (2026-04-24 ucrt)
- MonolixSuite / Simulx User Guide 2024R1

Para consultar as referências em formato de página web, acesse o arquivo [index.html](./index.html).
